# Dynami Blog Website 

Where users can create, read, edit and delete blog posts. All posts are saved in the browser using local storage.

# Pages info:
- index.html- Homepage that shows all blog posts.
- new-post.html- Page to create a new blog post. 
- post.html- Page to view, edit and delete a post.
